How to use
  1. Get data. In HOBOware choose File → Export Points as Excel Text (or the “Export Table Data” button) with “Export to a single file” selected. Open the resulting .csv here.
  2. Check units. Units are read from the file header when possible; otherwise set Source units. 12‑hr (AM/PM) and 24‑hr times are detected automatically.
  3. Explore. Cursor shows the date and temperature under the red crosshair (arrow keys or ◀ ▶ step one reading). Zoom: drag across either plot. Pan: drag to shift. Reset restores the full record. Both plots share the time axis.
  4. Filter. Filter passes Raw Data or the Daily Max to the green plot; Averaging then applies a daily, weekly (7‑day blocks from the first reading, plotted at noon on day 4), monthly or running average. For a running daily mean on hourly data use Raw Data + window 24 points; for MWMT‑style curves use Daily Max + window 7 days.
  5. Summarize. Drag the yellow (left) and orange (right) sliders on the green plot. Summary statistics use the raw readings between the sliders, regardless of the filter.
  6. Export saves what the green plot shows between the sliders as a WaTSS text file, which can be read back in.

Accepted format: two header lines (ignored), then comma‑separated rows of reading #, date time, temperature, e.g. 608,9/1/11 7:50:54 PM,51.19. Dates are month/day/year.

Screen for logger problems: a jagged, air‑like trace suggests the logger was dewatered (desiccation); unusually damped diel swings suggest burial in sediment.

Based on the WaTSS 3.0 user manual (Rogers, K. B. 2015, Colorado Parks and Wildlife).
